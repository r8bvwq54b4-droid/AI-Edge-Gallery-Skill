# AI Edge Gallery Skill

Public hosting for Google AI Edge Gallery Agent Skills.

## GitHub Operator

The `github-operator` skill lets Google AI Edge Gallery read and update repository files through the GitHub Contents API.

Skill URL:

`https://r8bvwq54b4-droid.github.io/AI-Edge-Gallery-Skill/edge-gallery/skills/github-operator/SKILL.md`

The JavaScript implementation is hosted at:

`https://r8bvwq54b4-droid.github.io/AI-Edge-Gallery-Skill/edge-gallery/skills/github-operator/scripts/index.html`

## Security

The GitHub token is supplied to the Edge Gallery skill through its secret mechanism and is never returned by the skill.

Use a fine-grained GitHub token with the minimum required repository Contents permissions.
